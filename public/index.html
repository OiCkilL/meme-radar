编辑备注

创建或更换 GMGN API

每次创建新的 GMGN API Key，都必须重新完成 Agent 公钥绑定。Meme雷达只是在本机代为生成本次公钥，不会跳过这一步。

  1. 复制下面的 Ed25519 公钥。
  2. 打开 GMGN 创建页面；如果没有自动填入，就粘贴公钥。
  3. 只开启“允许读取”，务必关闭“允许交易”。
  4. 创建后复制 API Key，回到 Meme 雷达粘贴并点击 ✓。
