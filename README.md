# Meme雷达开源版

作者：**Evan**（[GitHub @OiCkilL](https://github.com/OiCkilL)）

本仓库是在上游开源雷达上继续改的本地只读多链 Meme 候选扫描器。GMGN 做发现与标签，GoPlus 复核已支持链的合约风险，DexScreener 交叉校验市值、流动性和官网。Windows 与 macOS 共用同一套扫描逻辑。

它不碰钱包私钥，不签名，不 swap，也不下单。页面上的「可看」只表示进入人工研究清单，不是买入建议，也不保证代币安全或会涨。

感谢上游作者 **DeFi狙击手**（[X @bi_9527zx](https://x.com/bi_9527zx)）把 [nhovongoc0-max/meme-radar](https://github.com/nhovongoc0-max/meme-radar) 开源出来。扫描骨架、GMGN 只读接入、观察池和看板都来自那份工作。本 fork 在其上加了 1 分钟 K 线形态筛选（永久排除默认关闭）、可选 Nansen 复查、AVE 只读入口，以及页脚的本机中文语音提醒。

## 功能

支持 Solana、BNB 链、Base、以太坊、Robinhood Chain、Arc、Stable 七条链，设置里最多勾 1–3 条轮询。

「即时发现」读 GMGN 1 分钟活跃榜，目标约每 20 秒刷新；严格深审另跑，不用热度冒充安全结论。深审会看合约权限、LP、税率/貔貅、持仓、钱包样本、聪明钱、5 分钟盘面和价格行为。未知字段保持未知。

候选行可打开官网、GMGN、X，可映射链上还有 AVE 代币页。收藏、备注、桌面提醒、记录导出和影子表现跟踪仍在。Key 只存在当前电脑。

## 安全边界

HTTP 只监听本机回环地址，默认 `http://127.0.0.1:3791/`。设置接口用来配扫描链、收藏备注和本机 API Key，没有交易接口。

GMGN Key 写在 `state/gmgn-api-key`；创建 API 用的 Ed25519 私钥写在本项目受限状态文件里（目录 `0700`、文件 `0600`）。Key 和私钥不进命令参数、状态 JSON、日志、HTTP 响应或浏览器存储。页面只会拿到可公开上传的公钥。

浏览器只拿到字段白名单过滤后的状态。X 链接只供人看。筛选结果分「拒绝 / 待复核 / 可看」三档。影子表现要当前链攒满 50 个样本才有观察意义，不能当策略有效的证明。

## 安装与启动

本仓库按源码运行。需要 Node.js 22.23+ 或 24.5+。

```bash
git clone https://github.com/OiCkilL/meme-radar.git
cd meme-radar
npm run setup
npm start
```

终端保持打开。浏览器打开 `http://127.0.0.1:3791/`。`npm run open` 会在后台起服务并尝试打开浏览器。`npm run doctor` 检查环境，`npm test` 跑测试。

3791 被占用时：

```bash
RADAR_PORT=3792 npm start
```

启动器不会覆盖其他程序或另一份雷达占用的端口。

macOS 也可以双击 `安装并启动.command`。系统拦第一次打开时，右键该文件选「打开」。缺 Node 时脚本会从 nodejs.org 拉一份项目专用版本并校验 SHA-256。

Windows 10/11 x64 解压到可写目录后，用 `START-HERE-WINDOWS.bat` 或 `安装并启动.bat`。若出现「已保护你的电脑」，确认来源后选「更多信息 → 仍要运行」。关掉那个黑色窗口等于停掉雷达。

代理或 VPN 下 GMGN 超时：先让浏览器能打开 GMGN，打开代理软件的「系统代理」，再完全退出并重新启动雷达。

上游原项目仍提供便携包，见 [nhovongoc0-max/meme-radar Releases](https://github.com/nhovongoc0-max/meme-radar/releases)。那些包对应上游版本，功能不一定和本 fork 一致。

## 第一次使用

1. 打开看板后，点右上角齿轮，进入「系统设置与扫描调度」。GMGN Key 不在顶栏。
2. 在 **GMGN API** 里点「首次使用 / 创建 API」，复制本机生成的公钥。
3. 到 GMGN 创建 API，粘贴公钥。权限只开「允许读取」，关掉「允许交易」。
4. 把 API Key 贴回设置，点「确认」。验证成功才会写入本机并开始扫描。每次新建 Key 都要重新绑公钥，不能拿另一把 Key 的配对步骤凑合。
5. 在 **扫描设置与记录** 里勾 1–3 条链，点「保存扫描链」。
6. 可选：同一弹窗里配 Nansen、AVE；页脚左侧开语音提醒。

之后同一入口启动即可，已保存的 Key 不用重填。候选行上的官网、GMGN、X、AVE 都是给人点的，雷达不会自动下单。

## 看板怎么用

顶栏左侧切查看链，右侧是语言、外观主题（系统 / 浅色 / 深色）和设置。单链模式点链标签会改扫描链；多链时标签只改你在看哪条，不打断后台轮询。链图标上的「已接入」只表示第二数据源范围，不保证这次查询成功。

即时发现窗口和深审表分开。即时榜目标每 20 秒拉一次 GMGN 1 分钟成交额榜（最多 100 条），不等整轮深审。页面不可见或关掉自动更新后，大约 30 秒不再发新的即时请求，后台深审继续。多个标签页共用一条请求队列和 20 秒间隔。界面显示实际更新时间，超过 60 秒标陈旧。这不是 WebSocket，也不是抢跑。

即时窗口会先丢掉已知貔貅、刷量、高风险、创建不足 5 分钟和基础流动性不够的记录。未知风险仍标未核验。展示市值大约 1 万–50 万美元，可按 2 万–8 万优先、1 分钟成交额或新进榜排序。「新进榜」是相对上次有效快照新出现（含重新上榜），不是刚发币。两次快照的价格变化用真实间隔，不冒充 1 分钟 K 线。

「排队核验」只对已启用扫描链、通过初筛的最新线索开放，每轮最多占一个优先位，总审计预算不加大。队列最多 12 个、10 分钟过期，重启清空。共享 GMGN 额度，即时窗口也会耗点。

默认每轮最多深审 6 个币，还有时间预算。请求按端点权重串行。明确安全拒绝会提前结束。短期缓存最长 60 秒。限流就等冷却、降速，不绕过套餐。

收藏和备注在本机 `state/preferences.json`，最多 50 个收藏、500 条备注。收藏币掉出发现范围后仍会复查风险，不会因此重新变成通过候选。关掉某条扫描链后，该链不再复查，已有影子样本仍可能补历史价。

人工通过绑审核版本，最长 24 小时；风险一变要重新点。Solana 地址保留大小写。人工通过/忽略只存在当前浏览器；收藏备注由本机服务保存。

设置里的「开启桌面提醒」需要授权，并且页面保持打开。只提醒新候选、风险恶化和长时间扫描失败。相同事件 30 分钟去重。静音不删页面事件。

「导出记录」下载不含 Key 的 JSON（审计、影子样本、收藏备注、当前浏览器人工标记、观察池）。带个人备注的文件不要公开传。

「清除并断开 API」删掉本项目 GMGN Key，并禁用旧 Key 回退，不动全局 GMGN 配置。重新验证保存后才会再扫。

`npm start` 是前台调试，没有进程守护。电脑休眠或关机就不能扫。本版不装开机自启。

## 持续观察池

观察池单独存地址，不要求币还在榜上或通过初筛。发现入口返回的合法地址会进有容量限制的池子，也可以按当前查看链手动添加。榜上没有的币不会凭空出现。

手工条目可以写备注和「疑似 rug / 已毕业」。这些是用户标签，系统不会当成已核实的安全或毕业结论。

每轮最多给到期观察币留一个深审位，计入原来的数量和时间预算。常规复查间隔 2 分钟、5 分钟、15 分钟；硬拒绝或已隔离风险是 1 小时。这是最早到期时间，排队和限流会拖。

每条保留复查次数、最近 20 次审计、失败原因和这次读到的价格/市值/流动性。缺的就标未知，不用旧价冒充这次采样。离开发现范围只继续观察，不会自动变回通过候选。

明确貔貅或第二源 FATAL 会锁存风险，后面正常读数不自动解锁。用户点 rug 不会上这把锁。暂停停止新的深审；在途请求停不掉，但暂停之后的结果不再写入观察历史。

总容量 500。手工和已锁存风险不自动淘汰。自动记录在前 24 小时、未满 3 次审计时受保护。没空位就跳过新增自动记录，手工添加会报满。其余自动记录超过 7 天没被榜单看到可以过期。风险记录不会被容量清理洗白。

数据在 `state/watch-pool.json`，有备份，重启还在。没配 GMGN Key 或链未启用时只存地址，不采样。

## 设置里的可选项

Nansen 默认关，不影响 GMGN。打开后只在观察池或已有审计记录的复查里请求，首次普通发现深审不调用。保存 Key 时不做在线校验，真假要等后续复查。支持 Solana、BSC、Base、Ethereum、Robinhood；Arc 和 Stable 自动跳过。只拉普通持仓前 20 条，不含高级标签，不是全量分布，更不是安全结论。全进程最少隔 5 分钟、每轮最多 1 次真实请求；同一币成功样本 30 分钟内复用。失败、超时或不支持都不改 GMGN 原判定。配置在 `state/nansen-settings.json`（`0600`，不留历史备份）。文件坏了只停 Nansen。

AVE 在设置里存一把本机 Key，保存时只读探测行情和交易服务。雷达不签名、不下单。候选行在能映射的链上显示「AVE 交易」，打开 `pro.ave.ai` 代币页。没有邀请码或推荐参数。

页脚左侧是语音提醒。点「试听并开启」后，只对新进入扫描链候选的币用本机中文语音播报，优先女声。开关和音量在当前浏览器，不耗付费 API。页面必须开着。没有中文语音时按提示在系统里装，或点重试。仍要自己看证据。

扫描设置里有一项「形态命中后永久排除，不再复查」，默认关。关着时，1 分钟 K 线命中跳升窄平台或持续回撤只让当次变成待复核，观察池继续盯。打开后按链＋合约写入排除表，重启也还在；再关掉只是不再使用该表，不清已写入的项。形态检测只看已收盘 1 分钟 K 线；样本不够、冲突、断档或过期就返回未知，不当成诈骗定罪。

## 提速路径（SP v2.1，默认关闭）

设置环境变量 `THROUGHPUT_MODE=1` 后启用公平 lane、请求双预算、info 轻采样与逐币发布。关闭时行为保持旧路径；已写入的观察历史和风险锁不会被清掉。轻采样只更新行情字段，**不是**完整安全审核，也不能洗白已锁存风险。Nansen 在提速路径下改为旁路补证，主结论先按 GMGN 发布。预算账本在 `state/request-budget.json`（只含计数与时间戳，不含 Key）。没有受控线上对照时，不要把开启提速理解成已验证的盈利或识别率提升。

## 筛选效果怎么看

通过组按合约跟踪 5 分钟、15 分钟、30 分钟、1 小时、2 小时、6 小时、24 小时价格。掉榜或换查看链也不丢样本。缺窗口时用对应时刻附近已收盘 1 分钟 K 线补，记下实际时间和来源，不用现价冒充历史价。

深审拒绝组按合约哈希抽约五分之一对照，最多 200 条。两组分别给出到期数、完成数、缺失数和中位涨跌，不合成一个收益数字。缺价格不是零收益。拒绝组抽样只覆盖实际深审过的币。50 个样本是最低观察门槛。统计不含可成交性、滑点和手续费。

## 运行数据

GMGN 客户端固定为项目依赖 `gmgn-cli@1.5.7`，只用其中的只读能力。开源版不读环境变量、旧的 GMGN 全局配置或项目 `.env`。只有在本页完成 Agent 公钥创建、并通过读取权限验证的 Key 才生效。连接验证和日常扫描都不会把认证私钥或调试开关传给请求进程，也不调用 `follow-wallet`、swap 或下单。网页响应里不会出现私钥。

运行状态在 `state/`，日志在 `logs/`，自动下载的运行环境在 `.runtime/`。这些以及 `node_modules/` 不要进版本库或发布包。不要把 API Key 放进截图、代码或日志。
